# Processes

Short, repeatable procedures. Each one ends with evidence you can show someone else. Agents follow these exactly;
humans should too.

| Process | Use when |
|---|---|
| [`milestone.md`](milestone.md) | planning any chunk of work |
| [`module-change.md`](module-change.md) | an agent or human changes a server module |
| [`version-bump.md`](version-bump.md) | moving to a new SpacetimeDB release |
| [`playtest.md`](playtest.md) | running a private or public playtest |
| [`load-test-cadence.md`](load-test-cadence.md) | climbing the scale ladder |
| [`release.md`](release.md) | shipping a build to players |
| [`backup-restore.md`](backup-restore.md) | proving recovery |
| [`incident.md`](incident.md) | a live world is degraded |
| [`parallel-agents.md`](parallel-agents.md) | several agents work on one repo at once |
